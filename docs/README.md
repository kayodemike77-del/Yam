## Common Questions

### "My build is taking forever!"
✅ **Normal!** Builds take 30-60 minutes. See [FAQ](FAQ.md#q-how-long-does-the-build-take)

### "I don't see any artifacts!"
✅ Check if build is still running (yellow icon). Scroll to bottom of completed runs. See [FAQ](FAQ.md#q-i-triggered-a-build-but-dont-see-any-artifacts-whats-wrong)

### "Which variant should I download?"
✅ Firefox variant for Firefox impersonation, Chrome variant for Chrome/Edge/Safari. See [FAQ](FAQ.md#q-how-do-i-know-which-variant-firefox-or-chrome-to-use)
